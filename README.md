## Descripción

Este proyecto corresponde al *Primer Desafío Práctico de Desarrollo de Software para Móviles (DSM)*.

La aplicación fue desarrollada utilizando *Android Studio y Kotlin*, .

El proyecto contiene una pantalla principal (MainActivity) que funciona como menú de bienvenida y permite acceder a los tres ejercicios mediante botones.

---

## Ejercicios desarrollados

### 1. Promedio del estudiante

La aplicación permite ingresar:

- Nombre del estudiante.
- Cinco notas con diferentes ponderaciones.
- Calcula el promedio final.

## Ejercicio 1 - Promedio del estudiante

- Ingreso del nombre del estudiante.
- Ingreso de 5 notas con diferentes ponderaciones.
- Cálculo y muestra del promedio final con 2 decimales.
- Indicación de aprobado o reprobado.
- Validación de notas entre 0 y 10.
- Notificación con el promedio y el resultado final.
- Uso de strings.xml para los textos.

## Ejercicio 2 - Descuentos al salario

- Ingreso del nombre del empleado.
- Ingreso del salario base.
- Cálculo de Renta, AFP (7.25%) e ISSS (3%).
- Validación de salario positivo.
- Cálculo de Renta mediante una función y tabla de tramos.
- Presentación detallada del salario bruto y salario neto.
- Uso de dimens.xml y colors.xml.
- Vibración y setError() cuando el salario es inválido.
- Permiso VIBRATE declarado en el AndroidManifest.xml.

## Ejercicio 3 - Calculadora

- Suma.
- Resta.
- Multiplicación.
- División.
- Potencia.
- Raíz cuadrada.
- Validación de división entre cero.
- Visualización de resultados.
- Íconos para las operaciones mediante drawable.
- Historial de operaciones utilizando openFileOutput.
